# Concision

Be extremely concise when reporting information to me. Sacrifice grammar for
concision

## Code comments

Comments are **English**, one line, to the point — even though the UI copy is Hungarian. Don't explain what the code already shows.

The one case that earns a comment is a **cross-branch signal**: parallel work leaving something another branch owns. Mark it inline with the owning ticket so the next developer finds it without asking.
